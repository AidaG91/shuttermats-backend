# ShutterMats Backend

Backend API for ShutterMats, a platform that manages photographic coverage for Brazilian Jiu-Jitsu competitions.

## Tech Stack
- Java 17+
- Spring Boot 3.x
- Spring Web
- Spring Data JPA
- Spring Security
- H2 Database (development)
- Maven

## Getting Started

### 1. Install dependencies
This project uses Maven, so dependencies are handled automatically.

### 2. Run the application
```
mvn spring-boot:run
```

### 3. API Structure (initial)

- /events
- /requests
